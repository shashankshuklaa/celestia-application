# 🌌 Celestia — AI Cosmic Companion

Celestia is an immersive AI-powered astrology experience built with modern frontend architecture and cinematic mobile-first design principles.

The platform combines:
- daily horoscopes
- birth chart visualization
- zodiac compatibility insights
- conversational AI astrology guidance
- animated cosmic storytelling

Designed as a premium mobile web experience with fluid interactions, reusable UI systems, and AI-assisted development workflows.

# 🚀 Getting Started

## Clone Repository

```bash
[git clone https://github.com/shashankshuklaa/celestia-ai-astrology.git](https://github.com/shashankshuklaa/celestia-application.git)
```

---

## Install Dependencies

```bash
npm install
```

or

```bash
bun install
```

---

## Start Development Server

```bash
npm run dev
```

or

```bash
bun run dev
```
